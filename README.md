# Motus kawaii (Go)

Jeu Motus en terminal, Go + Bubble Tea + Lip Gloss. Version Ruby : [motus-kawaii](https://github.com/Gatshub/motus-kawaii), version Rust/Ratatui : [motus-rust](https://github.com/Gatshub/motus-rust).

- 5 à 9 lettres, 6 essais, première lettre donnée
- lettres colorées : rose (bien placé), bleu (présent), gris (absent) — adaptatif clair/sombre
- lettres bien placées reportées verrouillées
- définition Wiktionnaire à la fin

## Jouer
```
go build -o motus .
./motus
```
